Existing Margot artwork supplied the portrait style reference. All seven earlier season badges were reviewed for the S8 redesign; S4–S7 supplied image references. S8 uses emerald enamel, a silver frame and crescent crest, and gold lettering to distinguish it from S7. These are generated adaptations for this calculator.
