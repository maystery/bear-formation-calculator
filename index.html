!
Before you set these in game
You can't set an exact troop number in the bear formation screen. It won't account for the bonus rally capacity. The best approach is to set the ratio and calculate using the resulting number. When you set the formation at the button you can double check the ratios. Full rally and lack of archer can modify the ratios.

How it's calculated
  1. Troop ceiling — the scarcest type relative to its share: T_troops = min(Inf / r_inf, Cav / r_cav, Arc / r_arc)
  2. Each march has its own cap: a march with a hero leader uses base deploy cap + 3,000 × savage_level; a march with no hero is limited to the squad deployment capacity. Set either to 0 to treat it as unlimited.
  3. Deployable total: T = min(T_troops, sum of every march cap), then filled march by march up to each cap.
  4. Within each march: infantry = M × r_inf, cavalry = M × r_cav, archers = M × r_arc

Rounding uses largest-remainder so per-march numbers sum exactly to the total. Leave a capacity at 0 to treat it as unlimited.
