How it's calculated
  1. Troop ceiling — the scarcest type relative to its share: T_troops = min(Inf / r_inf, Cav / r_cav, Arc / r_arc)
  2. Each march has its own cap: a march with a hero leader uses base deploy cap + selected Savage Advantage bonus + active Fearless Roar bonus; a march with no hero is limited to the squad deployment capacity. Set either base capacity to 0 to treat that base limit as unlimited.
  3. Heroes take marches in the assignment priority shown above, with Hilde last. Untick one to drop it from the split — its march falls back to the squad capacity, so the total sent goes down.
  4. Deployable total: T = min(T_troops, sum of every march cap).
  5. Filling strategy: Balance marches distributes troops evenly across all marches as their caps allow. Fill in order fills March 1 to its cap, then March 2, and so on.
  6. Within each march: infantry = M × r_inf, cavalry = M × r_cav, archers = M × r_arc

Rounding uses largest-remainder plus a global reconciliation, so every march sums exactly to its total without using more troops than you own. Leave a capacity at 0 to treat it as unlimited.
